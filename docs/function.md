# Speakeasy 화면별 기능

Speakeasy는 발표 자료, 발표자 노트, 연습 오디오를 한 덱(deck) 단위로 관리하는 웹 앱이다. 아래 내용은 현재 구현된 화면 기준의 사용자 기능이다.

## 공통

- 덱은 슬라이드, 슬라이드별 노트, 공용 에셋으로 구성된다.
- 소유자 화면은 패스프레이즈가 필요하며, `?` 키로 해당 화면의 단축키 도움말을 볼 수 있다.
- 발표·스크립트·공유 화면은 동기화 room을 사용해 슬라이드와 fragment(단계별 노출)를 맞출 수 있다.
- 슬라이드에서 숨긴 항목은 발표·공유·내보내기에서 기본적으로 제외된다.

## 1. 덱 목록 · 가져오기 (`index.html`)

- 덱 목록 조회, 편집·발표·스크립트·발음 연습 화면으로 이동한다.
- HTML 파일 또는 URL로 슬라이드 덱을 가져온다.
- 노트 Markdown과 키 메시지 자료를 함께 가져올 수 있다.
- GitHub 등 원격 소스를 가져올 때 필요한 토큰을 해당 브라우저에서만 입력할 수 있다.
- 기존 덱을 원본 자료로 다시 가져오거나, 덱 전체를 삭제한다.
- 공유가 활성화된 덱은 읽기 전용 공유 화면 링크를 연다.

## 2. 슬라이드 편집 (`edit.html`)

- 덱 제목을 인라인으로 변경한다.
- 슬라이드 목록에서 선택, 드래그 정렬, 추가, 복제, 숨김/표시 전환을 한다.
- 캔버스에서 텍스트를 직접 편집하고, 16:9·세로 9:16·원본 HTML 모드로 확인한다.
- 슬라이드 HTML과 프레임(공통 HTML/CSS)을 편집한다.
- 슬라이드별 Markdown 노트를 작성하고 글자 크기를 조절하거나 TTS로 듣는다.
- 왼쪽 슬라이드 목록과 오른쪽 노트 패널을 접고, 데스크톱에서는 너비를 조절한다.
- 에셋 라이브러리에서 이미지·영상·음성·기타 파일을 업로드, 검색, URL 복사, 슬라이드 삽입, 이름 변경, 삭제한다.
- 공유 링크를 생성·복사·교체·해제한다.
- 버전 히스토리를 열어 슬라이드/노트/프레임의 이전 버전을 확인하고 복원한다.
- HTML, 브라우저 인쇄 PDF, PPTX, 노트 Markdown을 내보낸다.
- 현재 슬라이드의 발음 연습 패널을 열어 TTS, 녹음, 발음 평가를 이용한다.

## 3. 발표 (`present.html`)

- 덱을 전체 화면에 가깝게 발표하고 키보드·휠·터치로 슬라이드를 이동한다.
- fragment와 stepper 방식의 단계별 콘텐츠를 진행하거나 되돌린다.
- 진행 표시와 슬라이드 탐색 점을 제공한다.
- 발표 room으로 현재 슬라이드와 노출 단계를 방송한다.
- 발표자 패널에서 현재 슬라이드의 핵심 메시지·노트·다음 슬라이드·경과 시간을 본다.
- 발표자 패널의 글자 크기와 너비를 조절하고 패널을 숨길 수 있다.
- 발표자 패널에서 이중 언어 자막 스크립트를 불러와 실시간 자막을 시작·중지할 수 있다.
- 관객용 실시간 공유 링크를 복사한다.

## 4. 스크립트 리더 (`script.html`)

- 현재 슬라이드의 발표 노트를 텔레프롬프터 형태로 읽는다.
- 발표 동기화를 따르거나 수동 모드로 전환해 직접 이전/다음 슬라이드로 이동한다.
- 글자 크기와 하이라이트 표시를 조절한다.
- 슬라이드·노트 편집 화면 및 Markdown 노트 보기 화면으로 이동한다.

## 5. 전체 노트 편집 (`script-edit.html`)

- 모든 슬라이드의 노트를 한 화면에서 선택·편집한다.
- Markdown 미리보기를 켜고 끈다.
- 자동 저장, 수동 버전 저장, 히스토리 확인 및 복원을 지원한다.
- 슬라이드 편집·스크립트 리더·발표 화면으로 이동한다.

## 6. 노트 Markdown 보기 (`notes.html`)

- 덱 전체 노트를 읽기 전용 Markdown으로 표시한다.
- TTS 재생·중지, 클립보드 복사, `.md` 파일 다운로드를 지원한다.
- 스크립트 리더와 발음 연습 화면으로 이동한다.

## 7. 발음 연습 (`pronunciation.html`)

- 슬라이드별 노트로 발음 연습 대상을 선택한다.
- TTS 엔진과 재생 속도를 선택해 원고를 듣고, 생성된 음성을 다시 사용한다.
- 마이크로 녹음하고 본인 녹음을 재생한다.
- 브라우저 음성 인식 또는 설정된 STT 엔진으로 받아쓰기를 만들고, 원고 대비 점수·피드백을 표시한다.
- TTS 결과와 녹음 이력을 브라우저에 저장하고, 녹음을 선택한 폴더에 저장한다.
- 덱 전체의 연습 오디오를 하나의 파일로 내보낸다.

## 8. 공개 보기 (`view.html`)

- 공유 토큰이 포함된 URL로 덱을 읽기 전용으로 연다.
- 숨김 슬라이드를 제외하고, 원본 덱의 레이아웃·CSS·스크립트를 유지해 표시한다.
- 노트와 편집 기능은 제공하지 않는다.

## 9. 관객 화면 (`share.html`)

- 공개 보기와 동일한 읽기 전용 덱을 표시한다.
- 발표자의 room 상태를 따라 슬라이드와 fragment 단계를 실시간으로 맞춘다.
- 관객은 Follow/Stop으로 발표자 추적을 잠시 멈추거나 다시 시작할 수 있다.
- 발표자가 전송한 실시간 자막을 표시할 수 있다.

## 10. 라이브 자막 콘솔 (`captions.html`)

- 슬라이드별 한국어·영어 대본 Markdown을 불러온다.
- 발표 room을 구독해 현재 슬라이드를 자동으로 전환한다.
- 마이크 음성 인식으로 자막을 만들고, 영어가 없는 줄은 기계 번역으로 보완한다.
- 특정 대본 줄을 클릭해 관객 화면으로 즉시 전송한다.
- 인식 문장, 전송된 자막, 자막 전송 이력을 확인한다.

## 내부 화면

`edit-frame.html`은 슬라이드 편집 캔버스에 쓰는 단일 슬라이드 iframe이다. 직접 사용하는 화면이 아니라 `edit.html`이 내부적으로 연다.
